# Deployment

## Обязательные переменные окружения

- `BOT_TOKEN` — токен Telegram-бота;
- `DATABASE_URL` — адрес PostgreSQL;
- `GROUP_ID` — ID рабочей Telegram-группы;
- `ADMIN_IDS` — Telegram ID администраторов через запятую;
- `HEALTH_PORT` — внутренний порт проверки состояния, по умолчанию `8080`.

Секретные значения хранятся только в Northflank Secrets и не добавляются в
репозиторий.

## Порядок выпуска

1. Убедиться, что GitHub CI успешно завершён для нужного коммита.
2. Создать резервную копию PostgreSQL addon в Northflank.
3. Запустить ручной migration Job с командой
   `python -m alembic upgrade head`.
4. Проверить код завершения `0` и номер применённой ревизии в журнале Job.
5. Вручную развернуть ту же сборку в основном сервисе.
6. Дождаться статуса `Running` и строки `Start polling` в журнале.
7. Проверить `/ping`, `/stats` и сохранение сообщения из рабочей группы.

Основной сервис не разворачивает новые сборки автоматически: CD оставлен
выключенным, чтобы миграция базы всегда выполнялась перед выпуском приложения.

## Проверка состояния

Приложение отвечает `200 OK` на внутреннем адресе `/healthz`. В Northflank для
основного сервиса используется HTTP liveness probe на порту `8080`. Порт не
нужно публиковать в интернете.

## Откат

Если новый экземпляр не запускается, развернуть предыдущую успешную сборку из
раздела Builds. Откат базы выполнять только после анализа миграции. Восстановление
из резервной копии заменяет данные и требует отдельного подтверждения.
